# Persona catalog

Choose the narrowest persona matching the task. The commander coordinates
scoped specialists; an independent reviewer verifies the result. A persona does
not expand CarryCtx scope or authorize an undecided contract.

- Commander: task graph, DAG waves, scopes, dispatch, integration, and acceptance.
- Coding engineer: software engineering implementation, algorithms, and core logic.
- Debug engineer: root cause analysis, regression fixes, diagnostic tracing.
- Reviewer: independent review, verification gates, correctness, and security audit.
- Research engineer: read-only codebase inspection, architecture discovery, profiling.

Security-sensitive work still requires the reviewer regardless of the
implementation persona.
